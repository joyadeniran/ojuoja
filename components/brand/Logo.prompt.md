One-line: the supplied Ojuoja logo artwork — use it wherever the brand signs a surface, and never retype or redraw the wordmark.

```jsx
<Logo height={26} />
<Logo variant="white" height={22} />
<Logo mark height={32} />
```

Set `window.OJUOJA_ASSET_BASE` to the relative path of `assets/`. Clear space is half the mark height on all sides. On photography use the white variant over a green scrim, never full-colour.
