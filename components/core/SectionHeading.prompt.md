One-line: opens a section with a two- or three-word display headline, wrapped tight.

```jsx
<SectionHeading title={<>Closer Than<br />You Think</>} subtitle="Explore new flavors…" />
<SectionHeading align="center" title="Frequently Asked Questions" />
```

Break headlines manually with `<br />` — Ojuoja headlines are always short lines stacked, never a long single line.
